Formalizing the (untested) hypothesis about 4-bit inference distortion and planning the local deployment.

Audit note: The claim that graph edges are fully "invariant" under quantization is an untested hypothesis, not a proven fact. The prior citation to Dettmers et al. (NeurIPS 2022) has been corrected — that paper concerns 8-bit quantization and demonstrates outlier-preserving mixed precision, not 4-bit distortion.

1. Edge Inference and Spatial Deformation

3.1 The Geometric Cost of Quantization

Standard embedding models produce vectors in 16-bit or 32-bit floating point (FP16/FP32). Deploying inference at the edge often requires aggressive compression, such as 4-bit GGUF quantization, which maps continuous vector coordinates onto a discrete, lower-resolution grid.

It is well documented that transformer models contain a small number of "outlier" feature dimensions that are disproportionately important and disproportionately sensitive to precision loss during quantization (Dettmers et al., NeurIPS 2022, LLM.int8()). That paper specifically studies 8-bit quantization and shows that a mixed-precision decomposition — isolating outlier dimensions into higher precision — can preserve model performance without measurable degradation. It does not measure or claim severe distortion under 4-bit (INT4/GGUF) quantization specifically; that remains an open, testable question for embeddings, and we treat "4-bit embeddings show elevated nearest-neighbor instability" as an untested hypothesis pending the experiment in Section 3 below, not an established fact.

3.2 Graph-Anchored Retrieval as a Mitigation Hypothesis (Untested)

This motivates one design hypothesis behind Graph-RAG-anchored retrieval: if a relationship graph is built once from high-precision embeddings during ingestion, its edges could in principle be more stable under later quantization than raw distance computations performed at inference time on quantized vectors. This has not yet been empirically validated in this project.

The proposed mitigation is to traverse pre-computed graph edges for context retrieval at inference time, rather than recomputing nearest neighbors dynamically on quantized coordinates. Whether this meaningfully reduces quantization-induced retrieval errors is exactly what the Distortion Tracker script in Section 3 is designed to measure — it is a proposed experiment, not a demonstrated result.

3. Implementation: Distortion Tracker

This script is a proposed experiment (not yet run) to empirically measure the spatial shift (Procrustes distance) between high-precision embeddings and their GGUF counterparts. Results from running this script would be needed before treating the "graph anchor" hypothesis in Section 3.2 as validated.

import numpy as np
from scipy.spatial import procrustes
from sklearn.metrics.pairwise import euclidean_distances

class DistortionTracker:
    def __init__(self):
        self.fp16_embeddings = {}
        self.int4_embeddings = {}

    def log_embedding(self, chunk_id: str, vec_fp16: np.ndarray, vec_int4: np.ndarray):
        """Stores both the high-precision and edge-quantized vectors for comparison."""
        self.fp16_embeddings[chunk_id] = vec_fp16
        self.int4_embeddings[chunk_id] = vec_int4

    def calculate_manifold_deformation(self) -> float:
        """
        Uses Procrustes analysis to measure the structural deformation 
        between the FP16 continuous manifold and the INT4 discrete manifold.
        Returns a disparity score (0.0 = identical, higher = severely warped).
        """
        ids = list(self.fp16_embeddings.keys())
        if len(ids) < 2:
            return 0.0

        # Stack into matrices
        matrix_fp16 = np.array([self.fp16_embeddings[i] for i in ids])
        matrix_int4 = np.array([self.int4_embeddings[i] for i in ids])

        # Procrustes analysis aligns the matrices and calculates the disparity
        _, _, disparity = procrustes(matrix_fp16, matrix_int4)
        return disparity

    def topological_survival_rate(self, graph_edges: list[tuple], tolerance: float = 0.1) -> float:
        """
        Tests how well graph edge distances survive quantization.
        Calculates the fraction of edges whose Euclidean distance shift
        stays within tolerance between FP16 and INT4 embeddings.
        """
        survived = 0
        total = len(graph_edges)
        
        for u, v in graph_edges:
            # Original distance
            dist_fp16 = np.linalg.norm(self.fp16_embeddings[u] - self.fp16_embeddings[v])
            # Quantized distance
            dist_int4 = np.linalg.norm(self.int4_embeddings[u] - self.int4_embeddings[v])
            
            # If the distance shift exceeds tolerance, the edge distance is considered unstable
            if abs(dist_fp16 - dist_int4) <= tolerance:
                survived += 1
                
        return survived / total if total > 0 else 0.0
