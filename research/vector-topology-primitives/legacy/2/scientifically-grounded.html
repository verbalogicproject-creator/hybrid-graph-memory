1. Literature Review: The Foundations

These are the primary academic sources relevant to this project's individual components (manifold hypothesis, TDA, and Graph-RAG). Each entry below states what the source actually demonstrates, distinct from how it is being used architecturally in this project.

GRAPH RAG / MESHING

From Local to Global: A Graph RAG Approach to Query-Focused Summarization

Edge, D., et al. (Microsoft Research, 2024)

What it actually shows: This is the foundational Microsoft paper formalizing Graph-RAG for query-focused summarization. It establishes graph-structured retrieval as a real, published baseline. Use with care: the paper does not itself propose or validate a "geodesic mesh" interpretation — that framing is this project's own extension and should be labeled as such, not attributed to the source.

BACKGROUND ONLY — NOT DIRECTLY APPLICABLE

Advancing mathematics by guiding human intuition with AI

Davies, A., Juhász, A., Lackenby, M., et al. (Nature, 2021)

What it actually shows: A real, published paper in which a neural network flagged a correlation between a small set of hyperbolic-geometry parameters and a classical knot invariant (the signature), which mathematicians then used to manually formulate and prove a new theorem. Correction: this paper concerns pure knot theory and hyperbolic 3-manifolds; it says nothing about text embeddings, retrieval, or RAG. It should not be cited to "legitimize" combining knot theory with neural embeddings for retrieval — no such connection exists in the source, and the project's own knot-theory naming (Reidemeister moves, entanglement, etc.) has been removed elsewhere in this document set for this reason.

TOPOLOGICAL DATA ANALYSIS

Topology of Data

Carlsson, G. (Bulletin of the American Mathematical Society, 2009)

What it actually shows: A foundational, widely-cited survey establishing persistent homology as a rigorous method for inferring topological structure (connected components, loops, voids) from discrete point clouds by tracking feature persistence across distance scales. This is directly and accurately applicable to using persistent homology on embedding point clouds.

QUANTIZATION — CITATION CORRECTED

LLM.int8(): 8-bit Matrix Multiplication for Transformers at Scale

Dettmers, T., et al. (NeurIPS, 2022)

What it actually shows: This paper studies 8-bit quantization and shows that isolating a small number of outlier feature dimensions into higher precision (mixed-precision decomposition) preserves model performance without measurable degradation. Correction: it does not measure or claim severe distortion under 4-bit (INT4/GGUF) quantization, and should not be cited as proof that "4-bit edge models cause severe manifold distortion." That specific claim remains an untested hypothesis for this project, pending the Distortion Tracker experiment described in Phase 3.

3. Implementation: Automated Literature Ingestion

This Python script uses the public arXiv API to pull recent papers linking topology/persistent homology and language models, to help track the current state of this niche research area over time.

import urllib.request
import xml.etree.ElementTree as ET
from datetime import datetime

class LiteratureIngestor:
    def __init__(self):
        self.base_url = 'http://export.arxiv.org/api/query?'
        
    def fetch_topology_papers(self, max_results=5):
        """
        Queries arXiv for recent papers intersecting topology/manifolds and LLMs.
        """
        # Search query: (Topology OR Manifold OR "Persistent Homology") AND ("Large Language Model" OR LLM)
        query = 'search_query=all:"persistent homology" AND all:"language model"&sortBy=submittedDate&sortOrder=desc&max_results=' + str(max_results)
        url = self.base_url + query
        
        response = urllib.request.urlopen(url)
        data = response.read()
        root = ET.fromstring(data)
        
        papers = []
        # XML Namespace for Atom feed
        ns = {'atom': 'http://www.w3.org/2005/Atom'}
        
        for entry in root.findall('atom:entry', ns):
            title = entry.find('atom:title', ns).text.replace('\n', ' ').strip()
            summary = entry.find('atom:summary', ns).text.replace('\n', ' ').strip()
            published = entry.find('atom:published', ns).text
            
            papers.append({
                "title": title,
                "date": published[:10],
                "abstract": summary
            })
            
        return papers

    def generate_ctx_citations(self, papers):
        """Formats the fetched papers into .ctx format for the orchestration agent."""
        ctx_output = "[[SCIENTIFIC_CONTEXT]]\n"
        for i, paper in enumerate(papers):
            ctx_output += f"-> REF_{i+1}: {paper['title']} ({paper['date']})\n"
            ctx_output += f"   ABSTRACT: {paper['abstract'][:200]}...\n"
        return ctx_output
