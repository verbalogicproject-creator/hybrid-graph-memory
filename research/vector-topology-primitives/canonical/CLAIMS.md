## Language policy

- “Theorem” is reserved for a statement with definitions, assumptions, and proof.
- “Invariant” describes tested program behavior, not universal truth.
- “Empirical result” requires a frozen test set and the prespecified analysis.
- “Not significant” is not equivalence.
- “Not demonstrated” is the required conclusion when confirmation criteria fail.
- The legacy folder is historical input, not an evidence source for canonical claims.
